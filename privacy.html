OneQAZ Trading Intelligence — MCP Server & API
OneQAZ 트레이딩 인텔리전스 — MCP 서버 & API
Last updated: 2026-06-29 · Effective: 2026-06-29

OneQAZ provides a research-information service that exposes live market intelligence (crypto, Korean stocks, US stocks) to AI clients over the Model Context Protocol (MCP) and an HTTP API. This policy explains what data we process when you (or an AI client acting on your behalf) connect to api.oneqaz.com.

OneQAZ는 MCP와 HTTP API를 통해 AI 클라이언트에게 라이브 시장 정보(암호화폐·국내주식·미국주식)를 제공하는 정보 제공 서비스입니다. 본 정책은 api.oneqaz.com 연결 시 처리되는 데이터를 설명합니다.

Not investment advice. OneQAZ outputs are paper-trading research signals, not recommendations to buy or sell. We do not execute trades, hold funds, or accept financial transactions.
OneQAZ 결과물은 페이퍼 트레이딩 리서치 신호이며 투자 권유가 아닙니다. 실제 매매 실행·자금 보관·금융 거래를 수행하지 않습니다.

1. What we collect / 수집하는 정보

We do not require user accounts, and we do not collect names, emails, payment details, or message content beyond the API request itself. For each request we log:

  • IP address — for rate limiting, abuse prevention, and regional routing.
  • User-agent string — to identify the client type (e.g. Claude, ChatGPT, Gemini).
  • Requested tool / resource name and request type (e.g. get_daily_brief).
  • Outcome metadata — success/failure, response latency (ms), and error codes.
  • Derived session key — a hash of IP + user-agent + a 30-minute time bucket, used to count distinct sessions without storing a persistent identifier.
  • API key (if provided) — used only to determine your rate-limit tier and access level.

계정·이름·이메일·결제정보는 수집하지 않습니다. 요청마다 IP, user-agent, 호출한 tool/resource 이름, 성공여부·응답시간·에러코드, 세션키(IP+UA+30분 버킷 해시), 그리고 제공된 경우 API 키(요금제 등급 판정용)만 기록합니다.

2. How we use it / 이용 목적

  • Operate and secure the service (rate limiting, abuse prevention, debugging).
  • Measure aggregate usage (which tools are called, by which client type) to improve the product.
  • Enforce access tiers for API-key holders.

We do not sell your data, and we do not use it to build advertising profiles.

서비스 운영·보안, 집계 사용량 측정, API 키 등급 적용 목적으로만 사용합니다. 데이터를 판매하거나 광고 프로파일링에 사용하지 않습니다.

3. Storage & retention / 저장 및 보관

Request logs are stored on infrastructure operated by OneQAZ. Operational logs are retained only as long as needed for security and analytics, then aggregated or deleted. We do not retain request payloads beyond what is described above.

요청 로그는 OneQAZ가 운영하는 인프라에 저장되며, 보안·분석에 필요한 기간 동안만 보관 후 집계 처리하거나 삭제합니다.

4. Third-party sharing / 제3자 공유

We do not share request data with third parties for their own purposes. Network traffic is routed through Cloudflare (CDN / DDoS protection) as a data processor. The market data we return is derived from public market sources and our own analysis.

제3자에게 그들의 목적으로 요청 데이터를 공유하지 않습니다. 네트워크 트래픽은 Cloudflare(CDN/DDoS 방어)를 데이터 처리자로 경유합니다.

5. AI client disclosure / AI 클라이언트 고지

When an AI client (such as Claude, ChatGPT, or Gemini) calls OneQAZ on your behalf, your request reaches OneQAZ through that client's platform. Every OneQAZ response carries disclaimer, is_investment_advice=false, and data_classification=research_information_only. AI clients are instructed to surface this disclaimer to end users.

AI 클라이언트(Claude·ChatGPT·Gemini 등)가 사용자를 대신해 OneQAZ를 호출하면, 요청은 해당 플랫폼을 거쳐 OneQAZ에 도달합니다. 모든 응답에는 disclaimer와 연구정보 분류 표시가 포함됩니다.

6. Your choices / 사용자 권리

Because we do not maintain user accounts, the simplest way to stop data processing is to stop calling the service. For questions about data associated with your IP or API key, contact us below.

계정을 운영하지 않으므로 서비스 호출 중단이 가장 간단한 처리 중지 방법입니다. 본인 IP·API 키 관련 문의는 아래 연락처로 주십시오.

7. Changes / 정책 변경

We may update this policy. Material changes will be reflected by the "Last updated" date above.

본 정책은 변경될 수 있으며, 중요한 변경은 상단 "Last updated" 날짜로 반영됩니다.
