OneQAZ Trading Intelligence — MCP Server & API

Last updated 2026-10-07 · Effective 2026-10-07
CollectUseRetention SharingAI clientsChoices ChangesContact

OneQAZ provides a research-information service that exposes live market intelligence (crypto, Korean stocks, US stocks) to AI clients over the Model Context Protocol (MCP) and an HTTP API. This policy explains what data we process when you (or an AI client acting on your behalf) connect to api.oneqaz.com.

Not investment advice. OneQAZ outputs are paper-trading research signals, not recommendations to buy or sell. We do not execute trades, hold funds, or accept financial transactions.

01What we collect

We do not require user accounts, and we do not collect names, emails, or payment details from callers. For each request we log:

IP address
Rate limiting, abuse prevention, and regional routing. For requests routed through Cloudflare this is the client address Cloudflare reports.
User-agent
To identify the client type (Claude, ChatGPT, Gemini, etc.).
Tool / resource name
The requested tool or resource and the request type (e.g. get_daily_brief).
Outcome metadata
Success/failure, HTTP status, JSON-RPC error code, a short error description (at most 200 characters; input values echoed back by validation errors are redacted), latency (ms), and the shape of the result (rows returned, total available, whether it was truncated or empty).
Derived session key
A hash of IP + user-agent + a 30-minute time bucket. No cookie or other persistent identifier is set on your client.
API key (if provided)
Used to determine your rate-limit tier and access level. With each request we record the resolved tier and a one-way fingerprint of the key (the first 16 hex characters of its SHA-256 hash) so usage can be attributed per key. The key itself is never written to request logs.
Whitelisted request parameters
A limited summary of tool arguments (e.g. symbol, market, interval, category, date ranges, result limits, identifiers) and, for the search tool, the search keyword truncated to 60 characters. Calls made without arguments are recorded as such. Argument content outside this whitelist is not stored.
MCP client & protocol metadata
The client name/version sent at initialize (clientInfo), the MCP protocol version (MCP-Protocol-Version header or the initialize request), the Accept header (first 200 characters), the protocol session id header if your client sends one, the call order within a session, and request/response payload sizes.
Traffic classification
A derived label (crawler / operator-self-test / external) used to keep aggregate usage statistics honest.

We do not store the contents of responses we send you.

02How we use it

  • Operate and secure the service (rate limiting, abuse prevention, debugging).
  • Diagnose client and protocol compatibility problems.
  • Measure aggregate usage (which tools are called, by which client type) to improve the product.
  • Enforce access tiers and attribute usage to API keys.

We do not sell your data, and we do not use it to build advertising profiles.

03Storage & retention

Request logs are stored on infrastructure operated by OneQAZ, including internal analytics copies.

  • IP addresses, and the session key derived from them, are kept for up to 12 months. After that they are irreversibly replaced using a one-way transformation whose random key is discarded after each run, so the remaining records can no longer be linked to an IP address.
  • The rest of each request record (tool name, whitelisted parameters, outcome, client and protocol metadata) is kept as usage history. Once the IP-derived fields are replaced it no longer identifies you, except that requests made with an API key remain attributable to that key.
  • If you were issued an API key, the contact email attached to it is kept while the key is issued to you. You can ask us to delete it at any time.

04Third-party sharing

We do not share request data with third parties for their own purposes. Network traffic is routed through Cloudflare (CDN / DDoS protection) as a data processor. The market data we return is derived from public market sources and our own analysis.

05AI client disclosure

When an AI client (such as Claude, ChatGPT, or Gemini) calls OneQAZ on your behalf, your request reaches us through that client's platform. Every response carries disclaimer, is_investment_advice=false, and data_classification=research_information_only.

06Your choices

Because we do not maintain user accounts, the simplest way to stop data processing is to stop calling the service. For questions or requests (including deletion) about data associated with your IP address or API key, contact us below.

07Changes

We may update this policy. Material changes are reflected by the "Last updated" date above.

08Contact

Questions about this policy or your data: contact@oneqaz.com

This policy is published identically at oneqaz.com/privacy and api.oneqaz.com/privacy.

OneQAZ 트레이딩 인텔리전스 — MCP 서버 & API

최종 수정 2026-10-07 · 시행 2026-10-07
수집 정보이용 목적보관 제3자 제공AI 클라이언트이용자 선택 변경연락처

OneQAZ는 Model Context Protocol(MCP)과 HTTP API를 통해 AI 클라이언트에게 라이브 시장 정보(암호화폐·국내주식·미국주식)를 제공하는 리서치 정보 서비스입니다. 본 방침은 이용자(또는 이용자를 대신하는 AI 클라이언트)가 api.oneqaz.com에 연결할 때 처리되는 데이터를 설명합니다.

투자 권유가 아닙니다. OneQAZ의 결과물은 페이퍼 트레이딩 기반 리서치 신호이며, 매수·매도를 권유하지 않습니다. OneQAZ는 매매를 실행하거나 자금을 보관하거나 금융 거래를 받지 않습니다.

01수집하는 정보

회원 계정을 요구하지 않으며, 호출자의 이름·이메일·결제 정보를 수집하지 않습니다. 요청마다 다음을 기록합니다.

IP 주소
요청 수 제한, 남용 방지, 지역 라우팅. Cloudflare를 거친 요청은 Cloudflare가 전달한 클라이언트 주소입니다.
User-agent
클라이언트 종류(Claude, ChatGPT, Gemini 등) 식별.
tool / resource 이름
요청한 tool 또는 resource 와 요청 유형(예: get_daily_brief).
결과 메타데이터
성공·실패, HTTP 상태, JSON-RPC 오류 코드, 짧은 오류 설명(최대 200자 — 검증 오류가 되돌려 보낸 입력값은 가림), 응답 시간(ms), 결과 형태(반환 행 수, 전체 건수, 잘림·빈 결과 여부).
파생 세션 키
IP + user-agent + 30분 구간의 해시. 이용자 기기에 쿠키나 기타 영구 식별자를 남기지 않습니다.
API 키(제공한 경우)
요청 한도 등급과 접근 수준 판정에 사용합니다. 키별 사용량을 집계할 수 있도록 요청마다 판정된 등급과 키의 단방향 지문(SHA-256 해시 앞 16자리)을 기록합니다. 키 자체는 요청 로그에 기록하지 않습니다.
허용 목록 요청 인자
수요 집계를 위해 tool 인자의 제한된 요약(symbol, market, interval, category, 기간, 결과 개수, 식별자 등)과 search 도구의 검색어(최대 60자)를 기록합니다. 인자 없이 호출한 경우 그 사실만 기록합니다. 허용 목록 밖의 인자 내용은 저장하지 않습니다.
MCP 클라이언트·프로토콜 메타데이터
initialize 때 보낸 클라이언트 이름·버전 (clientInfo), MCP 프로토콜 버전(MCP-Protocol-Version 헤더 또는 initialize 요청), Accept 헤더(앞 200자), 클라이언트가 보낸 경우 프로토콜 세션 ID 헤더, 세션 내 호출 순서, 요청·응답 크기.
트래픽 분류
집계 통계를 정직하게 유지하기 위한 파생 라벨(크롤러 / 운영자 자체 점검 / 외부).

이용자에게 보낸 응답 본문은 저장하지 않습니다.

02이용 목적

  • 서비스 운영·보안(요청 수 제한, 남용 방지, 디버깅).
  • 클라이언트·프로토콜 호환성 문제 진단.
  • 제품 개선을 위한 집계 사용량 측정(어떤 tool 이 어떤 클라이언트에서 호출되는지).
  • 접근 등급 적용 및 API 키별 사용량 집계.

데이터를 판매하거나 광고 프로필을 만드는 데 사용하지 않습니다.

03저장 및 보관

요청 로그는 OneQAZ가 운영하는 인프라(내부 분석용 사본 포함)에 저장됩니다.

  • IP 주소와 IP에서 파생된 세션 키는 최대 12개월 보관합니다. 이후에는 실행마다 폐기되는 임의 키를 사용한 단방향 변환으로 비가역 치환해, 남은 기록을 IP 주소와 연결할 수 없게 합니다.
  • 나머지 기록(tool 이름, 허용 목록 인자, 결과, 클라이언트·프로토콜 메타데이터)은 사용 이력으로 보관합니다. IP 파생 항목이 치환된 뒤에는 이용자를 식별하지 않으며, 다만 API 키로 한 요청은 해당 키에 귀속된 채로 남습니다.
  • API 키를 발급받은 경우, 키에 연결된 연락 이메일은 키가 발급돼 있는 동안 보관합니다. 언제든 삭제를 요청할 수 있습니다.

04제3자 제공

요청 데이터를 제3자의 자체 목적으로 제공하지 않습니다. 네트워크 트래픽은 데이터 처리자인 Cloudflare(CDN·DDoS 방어)를 거칩니다. 응답으로 제공하는 시장 데이터는 공개 시장 자료와 OneQAZ의 자체 분석에서 나옵니다.

05AI 클라이언트 고지

AI 클라이언트(Claude, ChatGPT, Gemini 등)가 이용자를 대신해 OneQAZ를 호출하면, 요청은 해당 클라이언트의 플랫폼을 거쳐 도달합니다. 모든 응답에는 disclaimer, is_investment_advice=false, data_classification=research_information_only 가 포함됩니다.

06이용자의 선택

회원 계정을 운영하지 않으므로, 데이터 처리를 멈추는 가장 간단한 방법은 서비스 호출을 중단하는 것입니다. 본인 IP 주소나 API 키와 관련된 데이터에 대한 문의나 요청(삭제 포함)은 아래 연락처로 보내 주십시오.
